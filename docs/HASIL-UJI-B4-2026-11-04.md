# Hasil pemeriksaan B4 — 4 November 2026

## Pemeriksaan akhir persiapan demo

### Jejak Alumni siswa

Endpoint baca terpisah `GET /api/b4/student-alumni` dan `GET /api/b4/student-alumni/{id}` memakai `/jejak-alumni` serta detailnya, tidak pernah fallback ke direktori staff. Akun siswa pengguna berhasil membaca paginator asli dengan `data: []`; pengguna mengonfirmasi kondisi kosong tanpa alumni/profil contoh pada pratinjau. Halaman tidak menampilkan data demo saat sesi berakhir atau BE gagal. Tidak ada publikasi, perubahan izin, ataupun penulisan siswa/alumni dilakukan.

Detail masuk PT, prestasi dan timeline sudah mempunyai proyeksi eksplisit serta UI baca. Prestasi tidak meneruskan bukti privat, pivot, siswa_id atau bobot; nominal yang tidak tersedia tidak dijadikan nol, flag publish_financials=false menutup nominal, dan tahun saja tidak diubah menjadi tanggal. Karena daftar asli kosong, struktur detail terisi masih hanya diuji sintetis dan harus dicocokkan saat record berizin tersedia. Jangan mengklaim detail terisi telah lulus integrasi nyata. Pencarian/filter UI hanya berlaku pada halaman aktif karena kontrak filter endpoint siswa belum dirinci. Pagination tetap dari BE.

Regresi tahap siswa: **48 tes sintetis lulus**, build/TypeScript/lint lulus. Browser terisolasi memeriksa daftar, pagination, detail, tahun, progres, nominal yang tidak ditampilkan, kondisi kosong, dan ponsel tanpa overflow; tidak ada exception JavaScript ataupun operasi tulis B4. Perapian akhir membuat baris informasi pada kartu ponsel memakai lebar penuh. Web utama dimulai ulang pada port 3000 dengan build terbaru. Route pemeriksaan struktur sementara dihapus.

Pengguna mengonfirmasi PDF dari server BE tujuan berhasil terunduh lengkap melalui halaman analitik. Ini adalah konfirmasi pengguna; agen tidak memeriksa isi dokumen sekolah. Screenshot terbaru tanpa filter masih menunjukkan 0 alumni terpantau dan agregat kosong. Penyebab pada sumber BE belum dipastikan; jangan mengganti angka dengan jumlah penerimaan PT atau angka contoh. Pencocokan nilai `total` dan `measuredAlumni` terbaru diminta melalui sesi pengguna.

Lingkup tulis yang disetujui pengguna hanya informasi beasiswa, tidak termasuk siswa/alumni. CSV pada katalog menambah beasiswa baru melalui API katalog setelah pratinjau dan konfirmasi; bukan impor master siswa/alumni. Ekspor PDF memakai endpoint baca laporan BE dan token server. Pagination alumni mengikuti tombol nomor pada referensi desain dan metadata jumlah halaman BE.

Regresi: **44 tes sintetis lulus**, build/TypeScript/lint lulus. Browser membuktikan login salah ditolak, login benar berhasil, CRUD katalog beserta refresh, CSV siswa ditolak, template CSV terunduh, preview belum menulis, konfirmasi melakukan satu POST beasiswa, hasil bisa dibaca kembali, tombol tidak bisa menyimpan ulang, dan unduhan PDF berizin diterima. File PDF fixture hanya untuk tes transport API; renderer/isi PDF server sekolah belum diverifikasi. Tampilan pagination 1/2/.../30 dan warna halaman aktif diperiksa dengan data sintetis 599 penerimaan. Tidak ada exception JavaScript.

Tidak ada pengujian agen yang menulis ke BE sekolah. Pengguna mengizinkan commit/push ke branch b4 sesudah verifikasi. File pribadi, .env lokal, gambar uji di .next, dan konsep analitik terpisah tidak termasuk perubahan yang dipublikasikan.

## Tambahan: analitik beasiswa dan UKT/IPK

Analitik staff sudah memakai GET `/analitik-beasiswa` dan `/dashboard/ukt-ipk`. Struktur asli dibaca melalui sesi pengguna tanpa menyalin nilai identitas atau nominal pribadi ke fixture. Angka contoh tidak dipakai pada sesi staff, null tidak dianggap nol, dan jumlah penerima unik tidak diturunkan dari penjumlahan program. Distribusi IPK serta keberlanjutan yang tidak tersedia di BE ditampilkan sebagai belum tersedia.

Pemeriksaan browser asli membandingkan 13 nilai ringkasan/statistik serta jumlah elemen koleksi dengan respons langsung BE. Pengguna mengonfirmasi pesan **Lulus: angka sesuai BE**. Berkas receipt lokal tidak masuk, sehingga bukti ini adalah hasil browser yang dikonfirmasi pengguna, bukan receipt otomatis yang dibaca agen. Cakupan asli adalah snapshot saat pemeriksaan, dengan array agregat kosong dan min/maks/rata-rata nullable; bukan bukti seluruh varian data terisi atau seluruh kombinasi filter benar pada server tujuan.

Regresi terbaru: **32 tes sintetis lulus**. Browser sintetis memeriksa angka API, null, penerima unik yang tidak tersedia, filter, reset, penanganan gangguan tanpa data contoh, dan lebar ponsel. Build/TypeScript/lint lulus. Seluruh operasi ke BE asli hanya GET; alat pemeriksaan sementara dibersihkan setelah konfirmasi. Tidak ada perubahan data BE, commit atau push.

## Tambahan: respons alumni/timeline asli

Uji alur browser asli setelah perbaikan **lulus pada satu sampel**. Halaman pemeriksaan sementara memakai sesi admin pengguna, membuka daftar di iframe, mengikuti link timeline berdasarkan siswa_id, dan membandingkan tampilan dengan respons BE langsung. Hasil aman yang diterima agen: `sourceEvents: 1`, `projectionMatches: true`, `navigation: true`, `count: true`, `labelsAndTimes: true`, `passed: true`. Artinya satu kejadian dari BE tetap satu di tampilan, label/waktunya cocok, dan navigasi menuju siswa yang dipilih. Tidak ada nilai identitas, tahun aktual, kontak atau nominal disalin ke hasil pemeriksaan. Semua request ke BE berupa GET; POST hanya menyimpan boolean/jumlah pada FE lokal. Alat pemeriksaan sementara dihapus setelah hasil masuk, tanpa push.

Struktur daftar dan timeline asli telah diperiksa melalui GET dari sesi admin pengguna. Struktur daftar cocok dengan paginator dan relasi yang dipakai adapter. Timeline ternyata mengelompokkan kejadian pada `data[].events` berdasarkan `study_tracer_id`; adapter sebelumnya belum membuka kelompok tersebut. Perbaikan membuka seluruh kejadian, membaca `label` dan `year`, serta mempertahankan data dengan ketelitian tahun tanpa tanggal buatan.

Setelah perbaikan, 26 tes sintetis lulus. Browser sintetis memverifikasi label Lulus SMA dan tahun, navigasi daftar → timeline, detail progres, editor katalog dan lebar ponsel. Tidak ada nilai data sekolah disalin ke fixture atau laporan, tidak ada operasi tulis ke BE, dan tidak ada commit/push. Pemeriksaan asli ini berupa sampel pertama, bukan uji seluruh data sekolah atau seluruh varian progres.

Bagian di bawah mempertahankan hasil pemeriksaan sebelumnya; batas integrasi alumni/timeline diperbarui oleh tambahan ini dan catatan terbaru di `docs/INTEGRASI-API-B4.md`.

Pemeriksaan ini menguji implementasi FE yang ada, bukan menyatakan seluruh kontrak BE sudah terpasang dan terintegrasi. Tidak ada operasi tulis ke database sekolah, perubahan konfigurasi BE, commit, atau push dalam pemeriksaan ini.

## Bagian yang belum dapat diberi status lulus integrasi nyata

- Login dan katalog sudah memiliki jalur API, tetapi pengujian tulis kali ini dilakukan pada BE sintetis, bukan database sekolah. Laporan pengguna tentang berhasil login dan satu record katalog tidak menggantikan pemeriksaan seluruh field.
- Durasi program yang pada screenshot tertulis **Belum tercatat** masih perlu dicocokkan dengan payload simpan dan respons BE pada record uji yang disepakati. Tes sintetis membuktikan durasi angka bisa ditampilkan; belum membuktikan field tersebut disimpan oleh server tujuan.
- Filter lintas jenjang dan pagination BE nyata belum diverifikasi memakai kumpulan data nyata yang cukup.
- Alumni, timeline/progres, analitik, rekomendasi, chat, serta riwayat beasiswa sumber asli belum selesai integrasi FE–BE. Angka contoh tidak boleh disampaikan sebagai statistik sekolah.
- Belum menguji unggah/import, provider AI, PDF, worker, atau hak publikasi pada server BE tujuan.
- Tidak mengaudit seluruh kerentanan keamanan, seluruh perangkat/browser, maupun kesamaan visual per piksel dengan desain.
